# HAKS & CO Brand

Next.js + TypeScript + Tailwind + Framer Motion + GSAP + Three.js implementation of the supplied `index.html` and `checkout.html` experience.

## Run

```bash
npm install
npm run dev
```

## Pages

- `/` storefront with video hero, scroll-led editorial panels, 3D watch showcase, currency switching, and product cards.
- `/checkout` checkout flow with 3D product preview, payment method switching, validation, and order confirmation overlay.
